## Flagship: Vsesteklo CRM

**Live CRM:** [crm.vsesteklo.ru](https://crm.vsesteklo.ru/) (production — still in daily use)

Internal SPA for glass manufacturing: not a toy admin panel, but the ops hub for the business.

| Module | Role |
|--------|------|
| **Прайс-контроль** | Edit live site prices for mirrors & shower partitions (SKU search, categories) |
| **Калькулятор** | Engineering quote engine — geometry, thickness, edges, cutouts, hardware |
| **Заявки с сайта** | Website leads → sales pipeline |
| **Отчёты парсера** | Competitor/supplier price monitoring jobs |
| **Модерация отзывов** | Approve reviews before public site |
| **Аналитика за м²** | Sales/production analytics per m² |
| **Roles** | Admin, manager, engineer, measurer (+ clients, chat, logs, notifications) |

Flow: **site / calculator → lead → CRM deal → price & production control → public catalog**.

Full write-up: [vsesteklo/CRM.md](https://github.com/Arctillect-RK/vsesteklo/blob/main/CRM.md) (after push) · local `github-staging/vsesteklo/CRM.md`.
